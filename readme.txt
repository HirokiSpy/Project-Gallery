[Cara2 run Project]

Automatic run web secara local ke domain cloudflare:
 1. run script run_galeri.py (Win & Linux) @ start_galeri.bat (Win Only)

Untuk manual run:
 1. cmd ke dalam folder project 
 2. run python app.py
 3. buka cmd baru dan tulis dan enter cloudflared tunnel --url http://localhost:5000
